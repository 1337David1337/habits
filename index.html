        Архив

          Лучше держать 4–6 привычек. Архив прячет привычку, но сохраняет её отметки.

          Подключение открытьсвернуть

          1. Создай токен на github.com/settings/personal-access-tokens/new.
          2. Repository access → Only select repositories → репозиторий с данными.
          3. Repository permissions → Contents → Read and write.
          4. Вставь токен ниже. Он хранится только в этом браузере.
          Отметки хранятся в data.json приватного репозитория. Каждое сохранение — коммит.
