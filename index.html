                            Google Задачи

                            1. Открой script.google.com — создастся новый проект.
                            2. Сотри всё в редакторе и вставь код из google-tasks.gs. Сохрани.
                            3. Слева «Сервисы» → «+» → Google Tasks API → «Добавить».
                            4. Сверху выбери функцию setup → «Выполнить» → разреши доступ. Внизу откроется «Журнал выполнения» со строкой «Ключ для дашборда: …». Скопируй оттуда только ключ — 40 букв и цифр. Это не «Идентификатор развёртывания».
                            5. «Начать развёртывание» → «Новое развёртывание» → тип «Веб-приложение», запуск от твоего имени, доступ «Все». Скопируй URL.
                            6. Вставь URL веб-приложения и ключ из журнала ниже.
                            Подключение к GitHub

                            1. Создай токен на github.com/settings/personal-access-tokens/new.
                            2. Repository access → Only select repositories → репозиторий с данными.
                            3. Repository permissions → Contents → Read and write.
                            4. Вставь токен ниже. Он хранится только в этом браузере.

                            Данные хранятся в data.json приватного репозитория. Каждое сохранение — коммит.
