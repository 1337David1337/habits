# Keel — равновесие для отца

Статичный сайт на GitHub Pages: https://1337david1337.github.io/keel/

Код страницы публичный, данных в нём нет. Привычки и отметки лежат в `data.json`
приватного репозитория, который указывается в разделе «Подключение» на самой странице.
Страница читает и пишет этот файл через GitHub API. Каждое сохранение — отдельный коммит.

## Вкладки

- **Сегодня** — кнопки сна ребёнка и «я встал», одна карточка «Сейчас» (молитва, слот или вечерний ритуал —
  что актуальнее), лента дня (свёрнута до «дальше…»), главное с зарядом сфер и упором, привычки, задачи.
- **План** — обзор недели и гигиена задач, слоты на неделю, стратегические цели, баланс сфер, время вдвоём.
- **Молитва** — таймер, статистика, молитвенные нужды.
- **Сон** — прогноз подъёма, календарь, сон ребёнка.
- **Итоги** — неделя по привычкам, прогресс за месяц и квартал, время на цели.

Старые адреса `#morning` и `#goals` открывают «Сон» и «План».

## Слоты

Шаг для свободного слота выбирается только из открытых подзадач Google Задач: задача с подзадачами —
это проект, подзадачи — его шаги (списки «не предлагать» не участвуют). По «Готово» подзадача закрывается
и в Google Задачах, а время слота записывается на проект — его видно в «Итогах → Время на цели».
В `sessions.<дата HH:MM>` хранятся `taskId`, `listId` и `project`.

## Напоминания

Push-уведомления: утренняя молитва, вечерние 5 минут, обзор недели (воскресенье), свободный слот.
Устройство подписывается в «Настройках → Напоминания» (на iPhone — только когда Keel открыт с экрана «Домой»),
подписка хранится в `push.subs` файла `data.json`, время — в `settings.reminders`.
Отправляет GitHub Actions в репозитории с данными (`.github/workflows/remind.yml`, `.github/remind.mjs`)
по расписанию утром 5:00–9:00 и вечером 19:00–23:30 по Москве. Сделанное не напоминается:
молитва записана, ритуал пройден, обзор проведён. Отправленное за день — в `push-state.json`.
Открытый VAPID-ключ — в `app.js`, секретный — в секретах репозитория с данными.

## Тесты

Смоук-тесты на Playwright открывают страницу с вымышленными данными, GitHub API и мост Google Задач подменены.
Нужны Node.js и установленный Google Chrome:

```sh
npm install
npm test
```

## Демо

https://1337david1337.github.io/keel/?demo — вымышленная семья, чтобы показать Keel другим.
Хранилище в памяти вкладки, запросы к GitHub и Google Задачам подменены внутри страницы (`demo-data.js`):

## Подключение устройства

1. Создай fine-grained токен: https://github.com/settings/personal-access-tokens/new
   - Repository access → Only select repositories → репозиторий с данными;
   - Permissions → Repository permissions → Contents → Read and write.
2. Открой сайт, в разделе «Подключение» укажи `владелец/репозиторий` и вставь токен.

Токен хранится только в localStorage этого браузера.

## Google Задачи

Задачи приходят через веб-приложение Apps Script из `google-tasks.gs`: оно разворачивается
в своём Google-аккаунте и отдаёт задачи по ключу. Инструкция — в коде файла и в разделе
«Настройки дашборда» на странице. Адрес и ключ сохраняются в `settings` файла `data.json`.

## Формат data.json

```json
{
  "version": 1,
  "settings": {
    "cycleStart": "2026-09-14",
    "cycleWeeks": 12,
    "busyDays": [0, 1, 3],
    "busyLabel": "занято",
    "spheres": ["работа", "здоровье"]
  },
  "habits": [
    { "id": "sleep", "name": "Лечь до 23:30", "sphere": "здоровье",
      "target": 5, "order": 0, "archived": false, "created": "2026-09-14" }
  ],
  "log": { "2026-09-26": { "sleep": true } },
  "kid": { "2026-09-28": { "wake": "06:26", "bed": "20:40", "nights": ["23:40"] } },
  "me": { "2026-09-28": { "wake": "05:52" } },
  "together": { "2026-09-26": { "note": "прогулка" } },
  "reviews": { "2026-W39": "2026-09-27" },
  "goals": [
    { "id": "g1", "title": "Накопить на машину", "kind": "number", "start": 0, "target": 600000,
      "unit": "₽", "startDate": "2026-09-01", "deadline": "2027-05-31",
      "history": [{ "d": "2026-09-15", "v": 95000 }] }
  ]
}
```

`target` — сколько раз в неделю, `busyDays` и `slots[].dow` — дни недели с 0 = понедельник.
`kid.<дата>.bed` и `nights` относятся к ночи, которая начинается в этот день.

## Баланс сфер

У каждой сферы есть норма — сколько дней в неделю ей нужно время (`settings.sphereNorms`,
по умолчанию: жена 5, ребёнок 6, церковь/работа/деньги/здоровье 3, дом 1). Карточка «Упор на завтра»
на вкладке «Сегодня» предлагает по одному делу для сфер, которым по норме уже пора (↻ — другое дело).
Заряд сферы — дни с вниманием за 7 дней от нормы (2 из 5 = 40%), шкалы всех сфер видны на «Сегодня».
Повторное нажатие на выбранное предложение убирает его из главного и возвращает задаче прежнюю дату.
Задачи из списков «Когда-нибудь» и «Ожидание» не предлагаются, пока их не перенесут в другие списки.
Подробный баланс, нормы, ручные отметки, сферы списков и задач — во вкладке «План».
Сами считаются отметки привычек, выполненные задачи Google и «главное на день», шаги в слотах,
время вдвоём, молитва и вечера `busyDays`. В «Вечерних 5 минутах» есть шаг «Чему уделил время».

- `care.<дата>` — сферы, которым вручную отмечено внимание в этот день: `["ребёнок", "жена"]`;
- `settings.listSpheres.<название списка>` — сфера списка Google, `""` — угадывать по словам,
  `"__parked"` — не предлагать (по умолчанию так для «Когда-нибудь» и «Ожидание»);
- `tags.<id задачи>` — сфера задачи Google, выбранная вручную (`""` — без сферы).
  Без неё сфера угадывается по словам названия задачи; подзадачи берут сферу родителя.
